🚗 Uber Booking & Revenue Analysis Dashboard

 📊 Project Overview

This project presents an interactive Uber Booking & Revenue Analysis Dashboard developed using Microsoft Power BI.

The dashboard provides a visual overview of booking performance, revenue generation, distance traveled, vehicle types, payment methods, and monthly booking trends.

The main objective of this project is to transform raw booking data into meaningful business insights through interactive Power BI visualizations.

---

 🎯 Business Objective

The dashboard was created to help analyze:

- Overall booking performance
- Completed and lost bookings
- Revenue generated
- Monthly booking trends
- Revenue by vehicle type
- Revenue by payment method
- Total and average distance traveled
- Booking distribution across vehicle types

---

🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

 📈 Dashboard Analysis

1. Completed Bookings

A monthly trend visual shows how completed bookings changed throughout the year.

This helps identify:

- High-performing months
- Low-performing months
- Monthly fluctuations in booking activity

 2. Revenue by Vehicle Type

The dashboard analyzes revenue generated by different vehicle categories.

This helps understand which vehicle type contributes most to overall revenue.

 3. Monthly Booking Value

Monthly booking value is visualized to identify revenue patterns and changes throughout the year.

 4. Revenue by Payment Method

Revenue is analyzed across different payment methods such as:

- UPI
- Cash
- Uber Wallet
- Credit Card
- Debit Card

This helps identify the most commonly contributing payment channels.

 5. Distance Analysis

The dashboard tracks:

- Total distance traveled
- Average distance per booking

This provides an overview of trip distance and customer booking behavior.

---

💡 Key Insights

Based on the dashboard:

- Completed bookings account for a significant portion of the total booking volume.
- Booking activity varies across different months.
- UPI contributes the highest revenue among the displayed payment methods.
- Vehicle type has a significant impact on overall revenue.
- The dashboard provides a consolidated view of booking and revenue performance.
